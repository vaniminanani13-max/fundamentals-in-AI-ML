AI Virtual Painter Using Hand Gesture Recognition
1. Introduction

The AI Virtual Painter is a computer vision-based application that allows users to draw on a virtual canvas using hand gestures. The project uses a webcam to capture live video and detects the position of the user’s hand using MediaPipe. The index finger is used as a virtual drawing pointer.

When the user moves the index finger, the application draws a line on the screen. If the user raises both the index and middle fingers, the application switches to eraser mode. The user can also clear the complete canvas by pressing the C key and exit the application by pressing the Q key.

This project demonstrates the practical use of Artificial Intelligence, Computer Vision, Image Processing, and Human-Computer Interaction.

2. Objectives

The main objectives of this project are:

To develop a virtual painting application using Python.

5. Working Principle

The project works by continuously capturing video from the webcam. Each video frame is processed by the MediaPipe hand detection model.

The hand landmarks are detected and the coordinates of the index finger are obtained. Based on the position of the fingers, the application decides whether the user wants to draw or erase.

The working process is as follows:

The webcam captures the user’s hand.
OpenCV reads the video frame.
MediaPipe detects the hand.
The hand landmarks are identified.
The position of the index finger is calculated.
The application checks the finger gesture.
A line is drawn if drawing mode is selected.
The line is removed or erased if eraser mode is selected.
The final canvas is displayed on the screen.
6. Hand Gesture Recognition

The application uses finger positions to identify different actions.

Drawing Gesture

When only the index finger is raised, the application enters drawing mode.

The position of the index finger is used as the drawing point. As the user moves the finger, the application connects the previous position and the current position with a line.

Eraser Gesture

When both the index finger and middle finger are raised, the application enters eraser mode.

In this mode, the application draws using the background color. This makes it appear as though the existing drawing is being erased.

Clear Canvas

When the user presses the C key, the complete canvas is cleared.

Exit Application

When the user presses the Q key, the application closes.

7. Hand Landmarks Used

MediaPipe detects 21 hand landmarks. This project mainly uses the following landmarks:

Landmark 8: Tip of the index finger
Landmark 12: Tip of the middle finger
Landmark 6: Lower joint of the index finger
Landmark 10: Lower joint of the middle finger

The application compares the positions of these landmarks to determine whether a finger is raised or lowered.

For example:

If the index finger is raised and the middle finger is lowered, drawing mode is selected.
If both the index and middle fingers are raised, eraser mode is selected.
8. Algorithm
Start the application.
Open the webcam.
Create a blank virtual canvas.
Capture a video frame.
Convert the frame into RGB format.
Detect the hand using MediaPipe.
Find the required hand landmarks.
Check the position of the index finger and middle finger.
If only the index finger is raised, draw on the canvas.
If the index and middle fingers are raised, erase the drawing.
Display the canvas and webcam frame.
Check for keyboard input.
If C is pressed, clear the canvas.
If Q is pressed, exit the application.
Repeat the process until the user exits.

The project provides a simple and interactive way to perform digital drawing without using a mouse, keyboard, or touchscreen.

The AI Virtual Painter is a useful application of Artificial Intelligence and Computer Vision. It demonstrates how hand gesture recognition can be used to control a computer application in real time.
